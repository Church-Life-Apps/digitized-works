About this library

Source fidelity without the friction.

These editions preserve historic Christian writings while making them easier to search, navigate, and read. Each work links back to its source repository and release history.

The library checks for new stable releases automatically. If verification is overdue or an update cannot be safely imported, the site says so plainly instead of silently presenting an uncertain version.
